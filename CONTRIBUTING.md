# Guía de contribución

Este proyecto es desarrollado de manera individual para la Evaluación N°1 de la asignatura Ingeniería DevOps.

Aunque el desarrollo es realizado por un solo integrante, se utiliza un flujo de trabajo basado en GitFlow para mantener orden, trazabilidad y buenas prácticas en el repositorio.

## Estrategia de ramas

Se utilizan las siguientes ramas:

- `main`: contiene la versión estable del proyecto.
- `develop`: integra los cambios realizados durante el desarrollo.
- `feature/<nombre>`: utilizada para desarrollar nuevas funcionalidades.
- `hotfix/<nombre>`: utilizada para correcciones importantes.

Ejemplos:

```text
feature/horario
feature/contacto
hotfix/correccion-css
