## Control de cambios

Los cambios del proyecto se administran utilizando GitFlow y las siguientes ramas:

- `main`: version estable.
- `develop`: integracion de cambios.
- `feature/<nombre>`: nuevas funcionalidades.
- `hotfix/<nombre>`: correcciones urgentes.

Cada cambio importante se registra mediante commits y Pull Requests para mantener la trazabilidad del codigo.
