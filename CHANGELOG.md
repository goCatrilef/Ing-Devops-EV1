En este archivo se registran los principales cambios realizados durante el desarrollo del proyecto.

### Pendiente

- Continuar mejorando la documentación del repositorio.

## [1.1.1]

### Corregido

- Validación del cambio mediante GitHub Actions.

## [1.1.0]

### Agregado

- Nueva funcionalidad relacionada con el horario.
- Desarrollo realizado mediante una rama de tipo feature.
- Integración del cambio utilizando Pull Request.
- Ejecución automática del workflow de GitHub Actions.

## [1.0.0]

### Agregado

- Creación inicial de la landing page.
- Incorporación de estilos CSS.
- Incorporación de funcionalidades JavaScript.
- Creación del repositorio Git.
- Configuración de las ramas `main` y `develop`.
- Configuración de GitHub Actions.
- Configuración del despliegue automático hacia AWS EC2.
- Publicación del sitio utilizando Apache HTTP Server.

## Control de cambios

Los cambios del proyecto se administran utilizando GitFlow y las siguientes ramas:

- `main`: versión estable.
- `develop`: integración de cambios.
- `feature/<nombre>`: nuevas funcionalidades.
- `hotfix/<nombre>`: correcciones urgentes.

Cada cambio importante se registra mediante commits y Pull Requests para mantener la trazabilidad del código.# Changelog
